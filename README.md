# 건설현장 일일 안전보건 현장관리 시스템 — 배포 가이드

## 파일 구성
GitHub에 올릴 때 아래 파일을 **전부 같은 폴더(보통 저장소 루트)에 함께 업로드**해야 합니다.
- `index.html` — 프론트엔드 전체
- `map.jpg` — 단지 배치도 이미지
- `logo.png` — 회사 로고 (헤더 상단)
- `manifest.json` — PWA(앱처럼 설치) 설정 파일
- `sw.js` — PWA 서비스워커 (오프라인 캐시)
- `icon-192.png`, `icon-512.png` — PWA 앱 아이콘
- `gas-backend.gs` — (레거시) Google Apps Script 코드. 현재는 Firebase로 전환되어 더 이상 사용하지 않습니다. 참고용으로만 남겨둡니다.

데이터 저장/실시간 동기화는 Firebase(Realtime Database)로 이루어지며, 코드 안에 이미 프로젝트 설정이 들어있어 별도 설정 없이 바로 동작합니다.

## 📱 PWA (홈 화면에 앱처럼 설치)

이제 이 사이트를 휴대폰/PC에 **앱처럼 설치**할 수 있습니다.
- **아이폰(Safari)**: 사이트 접속 → 공유 버튼(⬆️) → "홈 화면에 추가"
- **안드로이드(Chrome)**: 사이트 접속 → 우측 상단 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가" (자동으로 설치 배너가 뜨기도 합니다)
- **PC(Chrome/Edge)**: 주소창 오른쪽의 설치 아이콘 클릭

설치하면 브라우저 주소창 없이 독립된 앱처럼 실행되고, `logo.png` 기반 아이콘이 홈 화면에 생깁니다.

### 재배포 시 주의사항
서비스워커는 **네트워크 우선(항상 최신 버전 먼저 시도, 실패시에만 캐시 사용)** 방식이라, 지금까지처럼 파일을 새로 올리고 새로고침하면 최신 버전이 바로 반영됩니다. 오프라인일 때만 마지막으로 접속했던 버전이 대신 보여집니다.

## 🔒 관리 탭

하단 네비게이션 맨 오른쪽에 **"관리"** 탭이 있습니다. 비밀번호(`6942`)를 입력해야 아래 기능을 사용할 수 있습니다.
- 일괄 작업 상태 변경 (날짜 선택 후 전체 예정/진행중/완료로 일괄 전환)
- 전경사진 변경 (날짜별 버전 관리)

일반 작업자들이 실수로 이 기능들을 건드리지 못하도록 분리했습니다. 비밀번호는 코드 안에 평문으로 저장되어 있어 강력한 보안은 아니며, 단순 오조작 방지 목적입니다.

## ✎ 작업 상세 → 수정 기능

기존에는 "복사"만 가능했는데, 이제 상세보기에서 **"✎ 수정"**을 누르면 작업등록 폼에 기존 내용이 그대로 채워진 채로 열립니다. 원하는 내용을 고친 뒤 "수정 완료"를 누르면 새 작업이 아니라 **기존 작업 자체가 업데이트**됩니다 (구글시트 연동 중이면 시트도 함께 업데이트).

## 이번 버전에서 반영한 것
업로드해주신 실제 화면 캡처를 기준으로 다시 만들었습니다.
- 실제 단지 배치도(101~119동) 이미지를 지도 배경으로 사용
- 작업등록: 동/층 복수선택(동은 101→119동 오름차순 정렬), 공종 직접입력, 고위험작업 세부 10개 항목, 위험성평가 상등급·유해물질 O/X 토글, 관리감독자(협력사/HDC — HDC는 실제 명단 드롭다운) 이원화, 안전감시단 배치+성명, 지도 드래그로 작업구간 지정(확정 후 삭제 전까지 유지)
- 장비 사용 여부 체크 시 사용 장비명을 바로 입력할 수 있는 입력창 노출
- 작업등록 화면 내 **양수기 위치 관리** 탭 신설 (No/업체/위치/규격/상태/등록일 + 지도 탭으로 위치 지정)
- 대시보드 지도에 작업 인원 핀(😊 인원수) + 양수기 핀(P, 상태별 색상) 동시 표시, 핀 탭 시 상세 시트 오픈
- 대시보드 전경사진 상단에 **사진변경 / 삭제(직전 사진으로 복원) / 확대보기** 버튼
- 작업 상세 시트: 복사/삭제, 도면 위치(구간) 하이라이트 표시
- 동별보기: 동 선택(오름차순) + 층별 필터 동시 지원
- "일일 고위험 작업 현황" 구글시트 내보내기 (아래 별도 안내)

※ 대시보드 지도는 캡처에 있던 초기 화이트 톤 디자인 기준으로 제작했습니다. 이후 확인하신 어두운 네이비 톤(pike.replit.dev) 스타일로 바꾸고 싶으시면 말씀해 주세요.

## 📤 "일일 고위험 작업 현황" 구글시트 내보내기

기존에 수기로 관리하시던 양식(상등급=빨강, 고위험=노랑, 일상작업=흰색 + 하단 번호 핀 항공사진)과 동일한 형태로, 앱에서 입력한 하루치 작업 데이터를 구글시트에 새 탭으로 내보내는 기능입니다.

### 사용 방법
1. **설정**에서 GAS 웹앱 URL을 먼저 등록합니다. (구글시트 바로가기 URL도 함께 등록하면 "시트 열기" 버튼으로 바로 확인 가능)
2. **대시보드** 하단의 **"📤 구글시트로 내보내기"** 버튼을 누릅니다.
3. 해당 날짜에 등록된 작업이 협력사별로 묶여, `일일현황_YYYY-MM-DD`라는 새 시트 탭으로 생성됩니다.
   - 위험성평가 상등급 → 행 전체 빨간색
   - 고위험 작업(상등급 아님) → 행 전체 노란색
   - 일반 작업 → 흰색
   - 표 하단에 배치도 위에 작업 번호가 찍힌 위치도 이미지가 자동 삽입됩니다 (🔴 상등급 / 🟠 고위험 / 🔵 일상)

### 이번에 폼에 새로 추가된 항목
내보내기 컬럼을 채우기 위해 작업등록 폼에 아래 항목이 추가되었습니다.
- 재해유형 (자유서술)
- 조출 여부 / 조출 시각
- 작업제외구역 (이격거리)
- 이동식 CCTV 설치 여부

### 아직 자동으로 채워지지 않는 항목
- **증거사진** 열은 빈 칸으로 생성됩니다. 사진 업로드 기능은 이번 범위에 포함하지 않았습니다(원하시면 추가 가능합니다). 내보낸 시트에서 직접 사진을 붙여넣어 사용하시면 됩니다.
- **위험요인 및 안전대책** 열은 선택하신 고위험 작업 항목과 비고를 바탕으로 간단한 문구가 자동 생성됩니다. 실제 제출용 문서라면 내보낸 후 시트에서 세부 내용을 다듬어 사용하시길 권장합니다.

### 주의사항
- 내보내기는 GAS로 `POST` 요청을 보내는 방식이라, 요청 전송 후에는 브라우저에서 바로 성공 여부를 확인할 수 없습니다(응답을 읽어올 수 없는 구조). 전송 후 잠시 기다렸다가 구글시트를 열어 새 탭이 생성되었는지 확인해 주세요.
- 같은 날짜로 다시 내보내면 기존 `일일현황_YYYY-MM-DD` 탭은 삭제되고 새로 생성됩니다(덮어쓰기).

## 📥 엑셀(.xlsx) 파일로 바로 다운로드

구글 연동 없이, 버튼 하나로 휴대폰에 .xlsx 파일을 바로 저장하는 기능입니다. 대시보드의 **"📤 일일 고위험 작업 현황 내보내기"** 버튼을 누르면 그날 등록된 작업이 실제 현장에서 쓰시던 양식과 동일한 열 구성으로 `일일현황_2026-08-12.xlsx` 파일이 즉시 다운로드됩니다.

**열 구성** (참고 양식과 동일):
No | 협력사명 | 동 | 층 | 작업내용 | 장비/작업발판 | 재해유형 | 작업인원(명) | 중점포인트 | 관리감독자(협력사) | 관리감독자(안전관리자) | 감시단 OR 안전전담자 | 작업계획서 OR 사전작업허가서(P.T.W) | 조출·야간(시간) | 이동식CCTV

- 위험성평가 상등급 → 행 전체 빨간색 / 고위험(상등급 아님) → 노란색 / 일반 → 흰색
- 표 하단에 배치도 위에 작업 번호가 찍힌 위치도 이미지 자동 삽입 (🔴 상등급 / 🟠 고위험 / 🔵 일상)
- **증거사진** 열은 참고 양식에는 있었지만, 사진 업로드 기능은 이번 범위에 없어 포함하지 않았습니다 (필요하시면 추가 가능)
- **중점포인트** 열은 작업 내용 상세 + 선택한 고위험 항목 + 위험성평가/유해물질/이격거리/비고를 자동으로 조합해서 채웁니다. 참고 양식처럼 아주 구체적인 절차 문구(예: "1.암석 소할 작업간 방음벽 설치")까지는 자동 생성하지 못하니, 실제 제출용이면 다운받은 엑셀에서 다듬어 사용하시길 권장합니다.
- 인터넷 연결은 엑셀 생성 라이브러리(ExcelJS, cdnjs)를 처음 불러올 때만 필요하고, 구글/GAS 설정과는 무관하게 동작합니다.
- 아이폰 Safari에서는 다운로드된 파일이 **파일(Files) 앱 → 다운로드** 폴더에 저장됩니다.

## 📷 전경사진 변경 / 삭제 / 확대보기

대시보드 지도 카드 상단의 세 버튼으로 전경(배치도) 사진을 직접 관리할 수 있습니다.

- **사진변경**: 앨범에서 사진을 선택하면 자동으로 리사이즈(최대 가로 1600px, JPEG 85% 압축)해서 이 기기(브라우저)의 localStorage에 저장하고 즉시 지도 배경으로 반영합니다.
- **삭제**: 방금 변경하기 전의 사진으로 되돌립니다. 사진을 저장해두지 않고 완전히 지우는 기능이 아니라 "직전 사진 복원(되돌리기)"이며, 되돌릴 사진이 없으면 안내 메시지가 뜹니다.
- **확대보기**: 사진을 전체화면으로 크게 보여줍니다. 이미지를 한 번 탭하면 확대/축소가 토글됩니다.

**주의**: 사진은 현재 이 브라우저(이 기기)에만 저장됩니다. 다른 사람이 접속했을 때도 같은 사진이 보이게 하려면 별도로 서버(구글 드라이브 등) 저장 기능을 추가해야 합니다 — 필요하시면 말씀해 주세요.

## 1단계. GitHub + Cloudflare Pages로 무료 배포하기

### GitHub에 올리기
1. GitHub에서 새 저장소(repository)를 만듭니다. (예: `site-safety-dashboard`)
2. `index.html`과 `map.jpg` **두 파일을 함께** 저장소 루트에 업로드(커밋)합니다.
   - "Add file → Upload files"에서 두 파일을 한 번에 끌어다 놓거나 선택하면 됩니다.
   - 아이폰에서는 GitHub 앱이나 모바일 웹의 "Add file → Upload files" 기능으로 가능합니다.
   - `map.jpg`를 빠뜨리면 배치도가 깨진 이미지로 보이니 꼭 같이 올려주세요.

### Cloudflare Pages 연결
1. https://dash.cloudflare.com 접속 → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**
2. 방금 만든 GitHub 저장소를 선택합니다.
3. 빌드 설정은 별도 프레임워크가 없으므로 다음과 같이 둡니다.
   - **Build command**: 비워둠
   - **Build output directory**: `/` (루트)
4. **Save and Deploy** 클릭 → 몇 초~1분 후 `https://프로젝트명.pages.dev` 주소가 발급됩니다.
5. 이후 GitHub 저장소에 새 커밋을 푸시할 때마다 Cloudflare Pages가 자동으로 재배포합니다.

> Cloudflare Pages는 정적 파일 호스팅이 무료이며 트래픽 과금이 없어(무제한 대역폭) 말씀하신 "트래픽 과금 이슈" 문제를 해결합니다.

## 2단계. Google Apps Script(GAS) 백엔드 배포

1. https://sheets.google.com 에서 새 스프레드시트를 만듭니다. (예: "일일안전보건현황_DB")
2. 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다.
3. 기본 생성된 `Code.gs`의 내용을 모두 지우고, 제공된 `gas-backend.gs` 코드 전체를 붙여넣습니다.
4. 상단 **배포 → 새 배포**를 클릭합니다.
   - 유형 선택(⚙️ 아이콘) → **웹 앱**
   - 설명: 임의로 입력 (예: v1)
   - **실행 계정**: 나(본인 계정)
   - **액세스 권한**: **모든 사용자** (앱에서 별도 로그인 없이 호출하기 위함)
5. **배포**를 클릭하면 웹 앱 URL이 발급됩니다.
   - 형태: `https://script.google.com/macros/s/AKfycb.../exec`
6. 이 URL을 복사해둡니다.

### 시트 구조
최초 1건이라도 데이터가 등록되면 `Tasks`, `Pumps` 두 시트가 자동 생성됩니다.

**Tasks 시트** (일일 작업)
id, date, company, taskName, workType, status, buildings, floors, location, workers, timeStart, timeEnd, detail, equipmentUsed, highRisk, platform, cutTool, riskGradeHigh, hazmat, director, supervisorCo, supervisorHDC, guardDeployed, guardName, remarks, regionX, regionY, regionW, regionH, createdAt

**Pumps 시트** (양수기 위치 관리)
id, no, company, location, diameter, count, status, regDate, x, y

- `buildings`, `floors`, `highRisk` 는 복수 선택 값이라 `|` 문자로 구분되어 한 셀에 저장됩니다. (예: `101동|102동`)
- `regionX/Y/W/H` 는 대시보드 지도 위에 드래그로 지정한 작업구간의 위치(%)와 크기(%)입니다.

## 3단계. 프론트엔드와 GAS 연결하기

1. Cloudflare Pages로 배포된 사이트에 접속합니다.
2. 화면 하단의 **⚙ 설정** 버튼을 누릅니다.
3. 2단계에서 복사한 GAS 웹 앱 URL을 붙여넣고 **저장 후 동기화**를 누릅니다.
4. 이후부터:
   - **작업등록** 탭에서 새 작업을 등록하면 자동으로 스프레드시트에 한 행씩 추가됩니다.
   - 앱을 새로 열거나 설정을 저장할 때 스프레드시트의 최신 데이터를 자동으로 불러옵니다(pull).

> 참고: GAS 웹앱은 브라우저의 CORS 프리플라이트 요청을 지원하지 않기 때문에, 등록(POST) 요청은 `no-cors` 모드로 전송됩니다. 이 경우 응답 내용을 직접 확인할 수는 없지만 스프레드시트에는 정상적으로 기록됩니다. 데이터가 잘 들어갔는지는 스프레드시트를 열어 확인하거나, 앱을 새로고침해 다시 불러오기(pull)하면 확인할 수 있습니다.

---

## 4단계. GAS 코드를 수정했을 때

Apps Script 코드를 수정한 뒤에는 **배포 → 배포 관리 → 배포 수정(연필 아이콘) → 새 버전으로 배포**를 해야 변경 사항이 실제 웹 앱 URL에 반영됩니다. (URL 자체는 바뀌지 않습니다.)

## 자주 발생하는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 설정 후에도 "동기화됨"이 안 뜸 | URL 끝이 `/exec`로 끝나는지 확인 (`/dev`가 아닌 배포용 URL이어야 함) |
| 데이터를 불러오지 못함 | 배포 시 액세스 권한이 "모든 사용자"로 되어 있는지 확인 |
| 등록은 되는데 목록에 안 보임 | 새로고침 시 pull이 자동 실행되므로, 앱을 완전히 재실행(새로고침)해 보세요 |
| 여러 명이 동시에 쓸 때 데이터 꼬임 | GAS는 동시 다중 쓰기에 최적화되어 있지 않으므로, 소규모(현장 관리자 1~3인) 사용을 권장합니다 |
